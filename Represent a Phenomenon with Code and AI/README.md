# 你还在听吗？

一个用 HTML、CSS、JavaScript 制作的单页互动模型，探索手机通知出现后，面对面谈话如何保持连续或暂时中断。

## 打开方式

双击 `index.html`，在浏览器中打开。选择一种通知，点击“向对方提出问题”，看完后用“体验另一个场景”比较。三个代码文件需要放在同一个文件夹里：

- `index.html`：页面结构和文字
- `style.css`：人物、手机、布局与动画
- `script.js`：两个场景的时间顺序、状态和提示音

页面没有外部素材，也不收集或发送数据。浏览器若阻止声音，视觉过程仍可正常播放。来电场景从停止回应到重新说话约 12 秒，整段从点击到结束约 18 秒。

## 作业材料

- `docs/design.md`：现象、计算思维、预期与实际测试结果
- `docs/sketch.md`：页面和两个场景的设计草图
- `docs/ai-process.md`：AI 提示、反馈、人的判断与修改过程
- `docs/submission-draft.md`：可用于整理 Google Doc 的英文初稿；发布网页后补入公开 URL 和截图

## 设计重点

两种情形都从同一个问题开始。普通弹窗中，对方看着手机仍能完整回答；来电中，对方拒接、打字并停顿，最后才回答。对方的视线、语言回应和等待时间是模型保留的三项关键特征。模型没有表示发送者身份或真实消息内容，因此不能据此断定通知类型造成了行为差异。
