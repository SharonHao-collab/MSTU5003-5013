# Design sketch

## One-screen layout

```text
┌──────────────────────────────────────────────────────────────┐
│ 你还在听吗？                                                 │
│ 你问了一个问题。对方的手机亮了。                              │
├────────────────────────────────────┬─────────────────────────┤
│ 面对面的场景                       │ 选择通知                │
│                                    │ [A 普通弹窗]            │
│          人物     手机              │ [B 来电]                │
│                                    │ [向对方提出问题]        │
│ 对话：“你觉得我们周末……”           │                         │
│ 此刻发生了什么                     │ 体验结束后的反思问题    │
├────────────────────────────────────┴─────────────────────────┤
│ 可观察的行为：视线｜语言回应｜谈话状态                         │
└──────────────────────────────────────────────────────────────┘
```

## Scenario A · 普通弹窗

```text
0 秒：你提出相同的问题
1 秒：对方开始回答
2 秒：短暂通知出现
3 秒：对方低头看手机
4–6 秒：对方仍看手机，同时完整回答“先去喝杯咖啡，然后逛公园”
7 秒：对方重新看向你
```

## Scenario B · 来电

```text
0 秒：你提出相同的问题
1 秒：对方说“我觉得……嗯……”
2 秒：手机响铃
3 秒：对方拒接来电并低头
4 秒：对方说“嗯……”
5–17 秒：对方打字，语言回应暂停，使用者真实等待约 12 秒
18 秒：对方完成之前的回答
```

两种场景用同一个问题和相近的最终回答，使使用者更容易注意“回答过程”的变化。
